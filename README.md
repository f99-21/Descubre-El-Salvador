# Explora SV · Portal de turismo nacional

🌐 **Sitio publicado:** https://TU-USUARIO.github.io/explora-sv/ 

## Ficha del proyecto
- **Nombre del portal:** Explora SV
- **Curso:** Desarrollo Web [Full Stack Junior] · Jóvenes Innovadores
- **Usuario objetivo:** Turistas nacionales y extranjeros que quieren descubrir destinos de El Salvador y planificar su viaje.
- **Objetivo del sitio:** Ayudar a descubrir, comparar y guardar destinos de las 7 regiones turísticas y facilitar la planificación del viaje.

## Equipo y roles (Fase 1)
| Integrante | Rol | Página a cargo |
|---|---|---|
| Nombre 1 | Coordinación | index.html |
| Nombre 2 | Diseño y UX | destinos.html |
| Nombre 3 | Desarrollo e integración | destino.html, favoritos.html |
| Nombre 4 | Contenido y documentación | planifica.html, nosotros.html |

## Requerimientos
- 6 páginas enlazadas entre sí, en HTML semántico y validado (W3C).
- Catálogo de 14 destinos (2 por región) en `datos/destinos.json`.
- Diseño responsivo (Fase 2), filtros, buscador, favoritos, formulario validado y clima (Fase 3), migración a React (Fase 4).

## Mapa del sitio
```
Inicio (index.html)
├── Destinos (destinos.html)
│   └── Detalle (destino.html?id=)
├── Favoritos (favoritos.html)
├── Planifica tu viaje (planifica.html)
└── Nosotros (nosotros.html)
```
